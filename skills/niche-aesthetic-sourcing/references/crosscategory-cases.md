# 跨品类判断校准

把贴纸案例中的规则迁移到其他品类：先看买家怎样使用，再分清变体、反例和落地成本；审美好评不能替代适配、履约与小批验证。

- **小卡/徽章配件**：展示或携带已有收藏，个性化由用户自己的收藏完成；先核槽位、卡套与承重。
- **通用娃衣**：以日常穿搭、材质和完整搭配承载审美；先核娃体尺寸，区分衣服、配件与娃。
- **原创微缩场景**：以非角色题材、灯光和成品展示吸引买家；装配体验与成品效果分别验证。
