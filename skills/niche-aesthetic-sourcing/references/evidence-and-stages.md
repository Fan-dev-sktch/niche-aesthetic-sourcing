# 证据与阶段

## 最小证据记录

每源记录 `id / url / title / publisher / independence_key / retrieved_at / content_origin / observation / limitations`，以及国家、渠道、数据时间、单品/全店范围、币种、计量单位和读取方式。缺日期就写未知，访问日期不等于内容新鲜日期。

schema 1.1/1.2的发现/待验证记录可以用 `retrieved_at: null`，同时填写 `date_unknown_reason`。账本的 `as_of` 不能代填逐源读取日。未注明读取日的来源可保留线索，不能用来通过门槛或商用准备条件；取得原始记录后更新。schema 1.0保留原先严格ISO日期规则。

`product_listing` 证明供给及页面标价；`customer_review` 提供购买或使用线索；`platform_sales_data / transaction_record / purchase_experiment` 才能提供定义清楚的支付指标。单条评论、全店销量、收藏及点赞不可换算成 SKU 销量。

`supplier_price_listing` 是公开样品/标价，不是针对我们的 `supplier_quote`。供应商网页声称耐水或交货快，不是 `fulfillment_test`。`channel_policy` 不是商品素材的 `rights_document`。

## 六项证据

| 项目 | 判断依据 | 常见误判 |
|---|---|---|
| demand | 目标市场、定义品类/SKU、明确时期与规模的实际购买 | 全店销量归给一款；评论数当订单数 |
| aesthetic_premium | 匹配材质、尺寸、功能、品牌、交付和市场的成交对照，或控制条件的付费试验 | 拿单张设计贴纸与随机100张包比价；忽略折扣、定制或品牌 |
| competition_gap | 人群需求、有效替代品、搜索覆盖及新进入者表现 | 少量搜索结果当低竞争；零热度当无需求 |
| unit_economics | 真实报价与完整整单成本、保守区间、资金及劳动 | 采购便宜即利润高；未知运费/CAC/税费填零 |
| rights_and_channel | 最终产品/宣传素材权利与真实卖家资格、渠道商品规则 | 有平台政策文件即有角色授权；在法国即可用法国主体 |
| fulfillment_fit | 实际样品、质量/适配、发货与退换方案 | 供应商宣传即履约验收 |

每门记状态、来源、反证、局限及下一次验证。未知不是失败；用户排除或方案已知不成立才淘汰。通用配件仍检查自己的设计与宣传。

## 阶段与风险

- `discovery`：有供给或人群线索，结论限于值得查。
- `validation`：补成交、比较、报价、权利和样品。可设计并在对应授权下做偏好研究、访问测试与样品检查。
- `test_ready`（schema 1.1/1.2）：具备有限付费试卖的声明准备条件。真实卖家渠道资格已核；产品权利与履约通过；具体报价、成本模型及售价/成本区间齐全；记录可承受试验损失、获客费用上限、成功/停止标准。**需求、审美溢价和竞争缺口可未知**，这正是试卖的问题。准备状态不等于得到发布或投放授权。
- `pilot_ready`：沿用旧账本的名称，表示六项证据已有声明通过；schema 1.1 还要求渠道资格与真实获客结果通过。不是扩量授权或未来盈利保证。
- `rejected`：具体方案被用户排除或已有关键反证；保存理由和可重新研究的条件。

保留schema 1.0/1.1历史记录；新轮用1.2。1.2的可试卖及已有经营证据阶段还需完整整轮资金计划。旧结构通过不能补出缺失的资格、获客或总资金证据。

## 可靠性的边界

批次检查器检查字段、引用与矛盾；不能独立判定样本代表性、支付事件真伪或是否消除混杂。人工逐一对照原始记录。没有完整交易/退款/获客记录时，不宣称模型已经学会赚钱。

读取受阻时记录边界，走允许的其他来源；重复受阻且只出现相同线索就停止该支路。关键事实发生冲突时保留来源与差异，不选择更符合偏好的数字。

## schema 1.2：整轮资金约束

选定一次有限试卖，按零收入、未售库存零回收的保守边界计算最高现金承诺：库存、样品/固定准备、获客、履约储备、费用税费退赔、其他承诺。各组互不重复，包含本轮既有支出、尚待结算和停止后仍须履行的承诺。不是只看一单亏多少。

引用真实报价、计划和成本记录；库存数量与报价MOQ、最高单价及入库运费分开，脚本核数量×单价+入库费。获客组覆盖整轮投放上限。总额必须同时在用户最新预算、试卖预算和可承受亏损内。自有劳动的机会成本仍在整单利润核算，现金支付的劳动也放入对应资金组。

准备多个备选计划不表示授权同时执行。并行试卖、共享投入或已经占用的预算须统一核总资金，不能每个候选各自重复使用同一预算；未核时不声明可一起执行。脚本仅核填写的金额和算术，不证明费用没有遗漏。
