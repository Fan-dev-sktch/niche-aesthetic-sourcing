# 小众审美选品

回答一个具体问题：**卖给谁，卖什么，为什么买，在哪里成交，一单能留下多少钱，怎样小规模验证。** 审美产生候选，购买与成本证据决定是否继续。

## 每次怎么做

1. **定范围。** 读取本轮最新决定与已有批次：卖家主体、买家国家、预算、设计/供应能力、偏好及排除项。只询问会改变当前决策的未知；主体和预算未知也能做公开研究，不能据此推荐立即开店或花钱。
2. **找候选。** 用“人群 × 用途 × 风格 × 产品”搜索原页、替代品和买家反馈，先覆盖不同购买理由。默认只保留最值得继续的1–3个候选；这控制输出长度，不是证据数量门槛。方法见 [研究操作表](references/research-playbook.md)。
3. **看实物，找反证。** 实际查看商品图片，分开记录图案/结构、材质、摄影、包装与功能。读具体使用反馈及差评，核规格和实际到手价。未看图就注明；漂亮、标价高、评论多，都不能直接证明有审美溢价或市场空缺。
4. **决定下一步。** 按 [证据与阶段](references/evidence-and-stages.md) 记录六项状态：需求、审美溢价、供给缺口、整单利润、权利/渠道、履约。用通过/未知/不通过，不做未经校准的总分或成功概率。指出最可能改变决策的一项缺口，先解决它。
5. **小测并复盘。** 选一个主成交渠道及一条获客路径。依据实际报价、样品、主体、权利、成本和总预算设计有限试卖，事先写访问/付款指标与停止条件。记录付款、费用、交付和退赔，更新判断；无有效访问时先诊断获客。

用户要求小总量、快增长或高利润时，分别记录这些条件的证据与未知；先按研究操作表核增长观察期和当前可比数据。

达到当前决策所需的用途、替代与反证覆盖就停止搜索。同店重复页面、已被证实无用的工具重试、为了凑样本量的资料，不继续收集。关键来源冲突时保留差异，先核最影响结论的事实。

## 按需读取

- 查品类：读 [研究操作表](references/research-playbook.md) 与 [证据与阶段](references/evidence-and-stages.md)。需要反例时才读 [案例簿](references/calibration-casebook.md)。
- 选平台、排上线：读 [渠道与试卖](references/channels-and-trials.md)。卖家国家、买家国家、发货地分别核；成交平台与获客渠道分别选。时间给条件和区间，不能承诺首单或回本日期。
- 算钱、复盘：读 [整单利润](references/economics-and-measurement.md)。未知成本保留未知；现金、劳动和固定投入说明边界。异质订单先分组或逐笔核算，再汇总。
- 需要保存或晋级：使用 [批次模板](assets/batch-template.json)、[格式示例](assets/discovery-example.json)，再读 [通过字段](references/pass-records.md)。快速讨论无需先填全模板；要声明可试卖或有经营证据，必须保存可追踪记录并检查。

本地工具：`python scripts/check_batch.py <batch.json>` 检查引用、矛盾和准备条件；`python scripts/analyze_trial.py <trial.json>` 计算 [订单模板](assets/trial-template.json)。它们不会验证网页真伪、权利、审美因果或未来盈利。新记录用schema 1.2；旧账本可读取，不能据旧结构补出新证据。

## 对用户怎么说

默认先给一句结论，再给最多3行候选表：**品类｜值得查的理由｜关键风险｜当前状态**，最后给最有价值的下一步。只解释会改变决定的证据，链接放在对应判断旁；完整来源和计算放进记录。用户只问一个品类时直接回答，不强塞比较表或流程介绍。

状态用“继续查 / 待验证 / 可有限试卖 / 已有经营证据 / 淘汰”。不得把研究通过说成盈利验证。平台、预算或时间未知时，明确是条件分支或规划假设。

## 使用边界

本技能面向海外消费者零售的小众审美和兴趣赛道。品类偏好、排除项、主体与预算以当前用户最新决定为准，不预设默认排除品类。贴纸、收藏配件、娃衣等是可按具体条件研究的候选。明星、二次元产品须核具体授权路径，也可研究原创风格及通用配件。

用户审美反馈记录“喜欢/不喜欢什么及理由”，用于下轮找候选；实际购买反馈另记，用于商业判断。读取既有批次和反馈，不假设永久记忆。

用当前允许的搜索、原页读取和账号数据工具。官方工具文档不代表已接入账号；新增费用、资格、库存和报价在相关决策前重查。搜索摘要仅作线索，店铺销量与聚合评论不能归给单品，供应网页不冒充报价或样品。

研究和本地记录按会话授权执行；联系、采购、开户、刊登、投放、发布、定时监控依据具体授权。模板不继承权限，准备状态不替代授权。不要安装外部选品代码、索取凭据或付费订阅来凑证据。
